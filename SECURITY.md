# Security Policy

This repository is the source for a static personal portfolio site. It has no backend, accounts or user data.

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately by email to
rupesh.inquiries@gmail.com.

Include what you found, where, and how to reproduce it. I'll reply within a few days.

## Scope

In scope: this repository's code and the deployed site's configuration (for example the headers in `public/_headers`).

Out of scope: third-party services (GitHub, Cloudflare, LinkedIn), and denial-of-service or automated scanner reports without a demonstrated impact.
